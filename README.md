# ☕ Saffron Brew Café

A modern café website built using **HTML, CSS, and JavaScript**.  
This project represents a **premium Indian fusion café website** with smooth UI and simple animations.

---

## 📌 Project Overview

Saffron Brew Café is a static website designed to showcase a café's brand, menu, and ambience.

It includes multiple pages such as:
- Home
- About
- Menu
- Gallery
- Contact

This project was created to practice **frontend web development and website structuring**.

---

## 🛠 Technologies Used

- HTML
- CSS
- JavaScript
- Python (for generating placeholder images)
